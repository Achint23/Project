**4. Demo Walkthrough (per D-04: numbered steps with expected outcomes)**
Section: "## Demo Walkthrough"

1. **Load a sample document** — Click sample loader in sidebar. (Document appears in sidebar list, processing status shows.)

3. **Get a summary** — Switch to 📝 Summary tab, click Summarize. (Business-readable summary generated.)
4. **Extract graph** — Switch to 🕸️ Graph tab, click Extract. (Entity table + interactive node-edge graph rendered.)
5. **Compare routing** — Switch to 🔄 Compare tab, type same question, click Compare. (Side-by-side results from large and routed models with latency/token metrics.)
6. **Try routing modes** — Use sidebar toggle (auto/small/large) then re-ask in Chat. (Model name and route reason displayed under answer.)

**5. Available Commands**
Table of all tasks.ps1 commands:
| Command | Description |
|---------|-------------|
| `.\tasks.ps1 setup` | Install dependencies, download EasyOCR weights |
| `.\tasks.ps1 run` | Launch Streamlit app |
| `.\tasks.ps1 test` | Run all tests |
| `.\tasks.ps1 doctor` | Verify environment + NIM connectivity |
| `.\tasks.ps1 clean` | Remove generated/cached files |
| `.\tasks.ps1 demo` | Run automated E2E demo dry-run |

**6. Troubleshooting (per D-05)**
Subsections:
- **Missing API key**: "Error about NVIDIA_API_KEY" → copy .env.local.example, add key
- **EasyOCR weight download fails**: proxy/firewall issues → manual download instructions
- **ChromaDB permission errors**: data/chroma/ directory permissions → run clean and retry
- **Port 8501 in use**: another Streamlit instance → `netstat -ano | findstr 8501` to find/kill
- **Python version mismatch**: "requires-python >=3.10,<3.13" → install correct version
- **uv not found**: installation link, or fallback to `pip install -r requirements.txt` pattern

**7. Architecture (per D-06: layout table from copilot-instructions.md)**
Section: "## Architecture"
Project layout table:
```
app.py                    # Streamlit composition root (thin)
core/                     # capabilities (config, llm_client, extractor, ocr, chunker, embedder, vectorstore, retriever)
pipelines/                # orchestration (ingest, query, summarize, graph, compare)
routers/model_router.py   # pure-function router with explainable RouteDecision
prompts/                  # externalized prompt templates
ui/                       # Streamlit view partials (upload, chat, summary_view, graph_view, comparison, sidebar)
data/samples/             # bundled sample PDFs (committed)
data/uploads/, data/cache/, data/chroma/   # runtime state (gitignored)
tests/                    # pytest test suite
```
Brief paragraph explaining: thin app.py → UI partials → pipelines → core modules → NVIDIA NIM API.

**8. Tech Stack**
