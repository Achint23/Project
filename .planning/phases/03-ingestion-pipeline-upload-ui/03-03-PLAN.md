From core/vectorstore.py:
```python
class VectorStore:
    def query(self, query_text: str, n_results: int = 5, doc_id: str | None = None) -> dict:
        """Query with optional doc_id filter. Returns raw ChromaDB query result dict."""
        embedding = self._embedder.embed_single(query_text)
        where = {"doc_id": doc_id} if doc_id else None
        return self._collection.query(
            query_embeddings=[embedding],
            n_results=n_results,
            where=where,
        )
```
