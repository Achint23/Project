Create `ui/upload.py` with:

1. **Singleton factory functions** at module top:
```python
@st.cache_resource
def get_nim_client():
    from core.config import get_settings
    from core.llm_client import NIMClient
    return NIMClient(get_settings())

@st.cache_resource
def get_ocr_reader():
    from core.ocr import OCRReader
    return OCRReader(languages=["en"])

@st.cache_resource
def get_vectorstore():
    from core.config import get_settings
    from core.embedder import Embedder
    from core.vectorstore import VectorStore
    embedder = Embedder(nim_client=get_nim_client())
    vs = VectorStore(persist_path="data/chroma", embedder=embedder)
    vs.validate_model()
    return vs
```

2. **`_init_documents(vectorstore)`** — if `"documents"` not in `st.session_state`, initialize as empty list. (ChromaDB doesn't store filenames, so we start empty and populate on upload. A manifest file approach is deferred.)

3. **`render_upload_ui(vectorstore, ocr_reader)`**:
   - `st.file_uploader("Upload a PDF document", type=["pdf"], key="doc_upload")`
   - If file uploaded: compute hash, check session_state known IDs, if known show `st.info` and return.
   - Call `save_upload(file_bytes, doc_id)`.
   - Wrap ingest in `with st.status("Processing document...", expanded=True) as status:` with `st.write` per stage.
   - On error: `status.update(label="Error!", state="error")` + `st.error(result.error)`.
   - On already_indexed: `status.update(label="Already indexed", state="complete")`.
   - On success: update label, append to `st.session_state.documents`.

4. **`render_sample_loader(vectorstore, ocr_reader)`**:
   - `samples_dir = Path("data/samples")`; if not exists or empty, return silently.
   - `st.subheader("📚 Sample Documents")`.
   - For each `*.pdf` in samples: show name + "Load" button. On click: read bytes, compute hash, check if already in session, if not run same ingest flow with st.status.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Streamlit | User uploads file via HTTP; Streamlit handles multipart |
| st.file_uploader → pipeline | File bytes cross from Streamlit widget to ingest logic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Denial of Service | st.file_uploader | mitigate | Set `server.maxUploadSize` in .streamlit/config.toml (default 200MB is acceptable for POC); type=["pdf"] whitelist |
| T-03-05 | Tampering | uploaded filename | mitigate | Never use original filename in file path; content hash is the filename on disk |
| T-03-06 | Spoofing | file extension | accept | st.file_uploader type filter is UI-only; PyMuPDF will fail gracefully on non-PDF bytes; acceptable for local POC |
</threat_model>
