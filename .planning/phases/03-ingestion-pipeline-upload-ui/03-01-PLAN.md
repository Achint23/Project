  <name>Task 1: Create pipelines package with ingest module</name>
  <files>pipelines/__init__.py, pipelines/ingest.py</files>
  <action>
Create `pipelines/__init__.py` (empty package marker).

Create `pipelines/ingest.py` with:
1. `IngestResult` dataclass: `doc_id: str`, `filename: str`, `chunk_count: int`, `page_count: int`, `already_indexed: bool = False`, `error: str | None = None`.
2. `compute_content_hash(file_bytes: bytes) -> str` — returns `hashlib.sha256(file_bytes).hexdigest()`.
3. `save_upload(file_bytes: bytes, doc_id: str, upload_dir: str = "data/uploads") -> Path` — saves bytes to `{upload_dir}/{doc_id}.pdf`, creates parent dirs with `mkdir(parents=True, exist_ok=True)`.
4. `is_already_indexed(vectorstore, doc_id: str) -> bool` — calls `vectorstore._collection.get(where={"doc_id": doc_id}, limit=1)` and returns `len(results["ids"]) > 0`.
5. `ingest_document(file_path, doc_id, filename, vectorstore, ocr_reader=None) -> IngestResult`:
   - Check `is_already_indexed`; if True return early with `already_indexed=True`.
   - Call `extract_document(str(file_path), ocr_reader)`.
   - Call `chunk_document(pages, doc_id)`.
   - Call `vectorstore.add(chunks, doc_id)`.
   - Return IngestResult with counts.
   - Wrap body in try/except catching Exception; log with `logger.exception` and return IngestResult with `error=str(e)`.
6. `delete_document(doc_id, vectorstore, upload_dir="data/uploads") -> None`:
   - Call `vectorstore.delete_by_doc(doc_id)`.
   - Remove `Path(upload_dir) / f"{doc_id}.pdf"` if it exists (`unlink()`).

Use `from __future__ import annotations` at top. Import from `core.extractor`, `core.chunker`. Use `logging.getLogger(__name__)`.
