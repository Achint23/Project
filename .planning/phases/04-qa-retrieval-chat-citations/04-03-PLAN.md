  <action>
Create `ui/chat.py` with:

1. **Imports:** `openai`, `streamlit as st`, `from pipelines.query import QueryResult, run_query`.

2. **`_init_chat()`** — If `"chat_messages"` not in `st.session_state`, set it to `[]`.

3. **`_render_citations(citations: list[dict], hallucinated_ids: list[str])`** — Render inside current chat message container:
   - If no citations and no hallucinated_ids: return
   - `st.caption("📚 Sources:")`
   - For each citation dict in `citations`: use `st.expander(f"[{cite['chunk_id']}] — page {cite['page_num']}")` and inside it `st.markdown(cite["text"])`
   - For each hallucinated ID in `hallucinated_ids`: `st.warning(f"⚠️ **[{hid}]** — Citation not found in retrieved chunks (possibly hallucinated)")`

4. **`render_chat(vectorstore, nim_client)`** — The main chat function:
   - Call `_init_chat()`
   - `st.subheader("💬 Ask a Question")`
   - Replay chat history: for each msg in `st.session_state.chat_messages`, use `with st.chat_message(msg["role"]):` then `st.markdown(msg["content"])`. If role is "assistant" and msg has "citations" key, call `_render_citations(msg["citations"], msg.get("hallucinated_ids", []))`.
   - Accept input: `question = st.chat_input("Ask a question about your documents")`
   - If question:
     - Display user message: `with st.chat_message("user"): st.markdown(question)`
     - Append to history: `st.session_state.chat_messages.append({"role": "user", "content": question})`
     - Display assistant response: `with st.chat_message("assistant"):`
       - Wrap `run_query` call in try/except catching openai exceptions:
         - `openai.RateLimitError` → `st.error("⚠️ NVIDIA API rate limit reached. Please wait a moment and try again.")`
         - `openai.APITimeoutError` → `st.error("⚠️ NVIDIA API request timed out. The model may be under heavy load — try again.")`
         - `openai.AuthenticationError` → `st.error("🔑 NVIDIA API authentication failed. Check your NVIDIA_API_KEY in .env.local.")`
         - `openai.APIStatusError as e` → `st.error(f"⚠️ NVIDIA API error (HTTP {e.status_code}): {e.message}")`
         - `openai.APIConnectionError` → `st.error("🌐 Could not connect to NVIDIA API. Check your network connection.")`
       - On exception: append error message to chat history as assistant message and return
       - On success: `st.markdown(result.answer)` then `_render_citations(result.citations, result.hallucinated_ids)`
       - Append to history: `st.session_state.chat_messages.append({"role": "assistant", "content": result.answer, "citations": result.citations, "hallucinated_ids": result.hallucinated_ids})`

| LLM output → Streamlit UI | LLM-generated markdown rendered in chat |
