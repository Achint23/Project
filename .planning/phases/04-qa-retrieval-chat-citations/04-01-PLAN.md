  <action>
Create `core/retriever.py` with:

1. **`RetrievedChunk` dataclass** with fields: `chunk_id: str`, `text: str`, `doc_id: str`, `page_num: int`, `chunk_type: str`, `distance: float`. Import from `dataclasses`.

2. **`reorder_chunks(chunks: list[RetrievedChunk]) -> list[RetrievedChunk]`** — If len(chunks) <= 1, return as-is. Otherwise return `chunks + [chunks[0]]` to duplicate the highest-scored (lowest distance) chunk at the end. ChromaDB returns results sorted by ascending distance (cosine space), so index 0 is already the best match.

3. **`retrieve(vectorstore, query_text: str, n_results: int = 5, doc_id: str | None = None) -> list[RetrievedChunk]`** — Call `vectorstore.query(query_text, n_results=n_results, doc_id=doc_id)`. Parse the raw dict result: iterate `raw["ids"][0]`, `raw["documents"][0]`, `raw["metadatas"][0]`, `raw["distances"][0]` to build `RetrievedChunk` objects. Guard for empty results (`if not raw["ids"] or not raw["ids"][0]: return []`). Call `reorder_chunks()` on the result before returning.

Type annotation for `vectorstore` parameter: use the existing `VectorStore` type from `core.vectorstore`. Import at top of file.
