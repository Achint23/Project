  <action>
Create `pipelines/query.py` with:

1. **Imports:** `re`, `dataclasses` (dataclass, field), `pathlib.Path`, `core.llm_client.NIMClient`, `core.retriever.RetrievedChunk`, `core.retriever.retrieve`, `core.vectorstore.VectorStore`.

2. **`QueryResult` dataclass** with fields:
   - `answer: str` — LLM-generated answer text
   - `citations: list[dict] = field(default_factory=list)` — valid citation details (each dict has keys: chunk_id, text, page_num, chunk_type)
   - `hallucinated_ids: list[str] = field(default_factory=list)` — chunk IDs cited but not in retrieval set
   - `retrieved_chunks: list[RetrievedChunk] = field(default_factory=list)` — all chunks from retrieval

3. **`_load_prompt_template() -> str`** — Read `Path("prompts/qa.txt").read_text(encoding="utf-8")`.

4. **`_format_context(chunks: list[RetrievedChunk]) -> str`** — For each chunk, format as `[{chunk.chunk_id}] (page {chunk.page_num}):\n{chunk.text}`. Join with `"\n\n"`.

5. **`_parse_citations(answer: str) -> list[str]`** — Use `re.findall(r'\[([^\[\]]+)\]', answer)` then filter to only IDs matching `re.compile(r'^[a-f0-9]+_chunk_\d+$')`. This prevents markdown links and other bracketed text from being misidentified as citations.

6. **`_validate_citations(cited_ids: list[str], retrieved_ids: set[str]) -> tuple[list[str], list[str]]`** — Return `(valid, hallucinated)` where valid = IDs in retrieved_ids, hallucinated = IDs not in retrieved_ids.

7. **`run_query(question: str, vectorstore: VectorStore, nim_client: NIMClient, n_results: int = 5, doc_id: str | None = None) -> QueryResult`** implementing:
   - Call `retrieve(vectorstore, question, n_results=n_results, doc_id=doc_id)`
   - If no chunks returned: return `QueryResult(answer="No relevant content found. Please make sure documents are indexed.")`
   - Build prompt: `_load_prompt_template().format(context=_format_context(chunks), question=question)`
   - Call `nim_client.chat(messages=[{"role": "user", "content": prompt}], temperature=0.3, max_tokens=1024)`
   - Extract answer: `response.choices[0].message.content`
   - Parse citations with `_parse_citations(answer)`
   - Validate with `_validate_citations(cited_ids, {c.chunk_id for c in chunks})`
   - Build citation detail dicts for valid IDs using chunk lookup: `{c.chunk_id: c for c in chunks}`
   - Return `QueryResult(answer=answer, citations=citation_details, hallucinated_ids=deduplicated_hallucinated, retrieved_chunks=chunks)`
  </action>
