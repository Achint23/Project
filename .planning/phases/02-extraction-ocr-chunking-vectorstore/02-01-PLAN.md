<task type="auto">
  <name>Task 2: Create core/extractor.py — PDF text extraction with table detection and OCR routing</name>
  <files>core/extractor.py</files>
  <read_first>core/config.py, core/ocr.py (will exist after Task 3, but code defensively)</read_first>
  <action>
Create `core/extractor.py` with:

1. `extract_tables(page) -> list[dict]` — Uses `page.find_tables()` from PyMuPDF 1.24+. Each table becomes a dict with keys: `text` (markdown via `table.to_markdown()`), `chunk_type` = "table", `page_num`, `table_index`.

2. `extract_pages(pdf_path: str) -> list[dict]` — Opens PDF with `pymupdf.open(pdf_path)`. For each page:
   - Extract tables first via `extract_tables(page)` — append to results
   - Extract text via `page.get_text("text", sort=True)` (reading-order sort)
   - Check OCR threshold: `len(text.strip()) < 50` → set `needs_ocr = True`
   - Return list of page dicts with keys: `page_num`, `text`, `needs_ocr`, `chunk_type` = "text"
   - Close the doc in a finally block

3. `extract_document(pdf_path: str, ocr_reader=None) -> list[dict]` — Full pipeline:
   - Calls `extract_pages()` to get page-level content
   - For pages where `needs_ocr` is True: if `ocr_reader` is provided, call `ocr_page(page, ocr_reader)` from `core.ocr`; otherwise skip with a warning
   - Returns flat list of all content dicts (tables + text + OCR results)
   - Each dict has: `text`, `chunk_type` ("text" | "table" | "ocr"), `page_num`

Key design:
- Use `pymupdf` import (not `fitz` — modern PyMuPDF convention)
- `extract_document` reopens the PDF to get page objects for OCR rendering (since extract_pages only returns text)
- Handle empty PDFs gracefully (return empty list)
- Minimal error handling: let PyMuPDF exceptions propagate (system boundary validation happens at pipeline level in Phase 3)
  </action>

<task type="auto">
  <name>Task 3: Create core/ocr.py and unit tests for extractor + OCR</name>
  <files>core/ocr.py, tests/test_extractor.py, tests/test_ocr.py</files>

  <action>
1. Create `core/ocr.py` with:

   - `class OCRReader`: Wrapper around EasyOCR Reader.
     - `__init__(self, languages=None)`: Defaults to `['en']`. Stores config but does NOT instantiate Reader yet (lazy).
     - `_get_reader(self)`: Lazily creates `easyocr.Reader(self.languages, gpu=False)` on first call, caches in `self._reader`.
     - `reader` property: Returns `_get_reader()`.

   - `def ocr_page(page, reader: OCRReader) -> str`:
     - Renders page to pixmap: `pix = page.get_pixmap(dpi=200)`
     - Converts to numpy array: `np.frombuffer(pix.samples, dtype=np.uint8).reshape(pix.height, pix.width, pix.n)`
     - Calls `reader.reader.readtext(img, detail=0, paragraph=True)`
     - Returns joined text: `"\n".join(results)`

   - Import numpy at top level.

2. Create `tests/test_extractor.py` with:
   - `test_extract_pages_digital_pdf`: Mock `pymupdf.open` to return a fake doc with pages that have >50 chars text. Assert `needs_ocr` is False.
   - `test_extract_pages_scanned_pdf`: Mock page with <50 chars. Assert `needs_ocr` is True.
   - `test_extract_tables`: Mock page.find_tables() returning a mock table with `to_markdown()`. Assert chunk_type is "table".
   - `test_extract_document_no_ocr_reader`: Call with ocr_reader=None, pages needing OCR get skipped gracefully.

3. Create `tests/test_ocr.py` with:
   - `test_ocr_reader_lazy_init`: Create OCRReader, assert `_reader` is None before first access.
   - `test_ocr_page_calls_readtext`: Mock easyocr.Reader, mock page.get_pixmap(). Assert readtext is called with the image array.
   - Use `unittest.mock.patch` for EasyOCR and pymupdf mocks.
