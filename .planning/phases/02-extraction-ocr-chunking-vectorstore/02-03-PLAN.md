<task type="auto">
  <name>Task 2: Create core/vectorstore.py — ChromaDB wrapper with model validation</name>
  <files>core/vectorstore.py</files>
  <read_first>core/embedder.py, core/config.py</read_first>
  <action>
Create `core/vectorstore.py` with:

1. `class VectorStore`:
   - `__init__(self, persist_path: str = "data/chroma", embedder: Embedder | None = None)`:
     - Creates ChromaDB `PersistentClient` with `Settings(anonymized_telemetry=False)`
     - Stores embedder (lazy-creates if None)
     - Calls `self._get_or_create_collection()` to set `self._collection`

   - `def _get_or_create_collection(self)`:
     - Uses `client.get_or_create_collection(name="documents", metadata={...})`
     - Metadata: `{"embedding_model": self._embedder.model, "embedding_dim": self._embedder.dim, "hnsw:space": "cosine"}`

   - `def validate_model(self)`:
     - Reads `self._collection.metadata`
     - Compares stored `embedding_model` against `self._embedder.model`
     - Compares stored `embedding_dim` against `self._embedder.dim`
     - If mismatch: raises `RuntimeError` with clear message: "Collection was built with '{stored_model}' but current config uses '{current_model}'. Delete data/chroma/ and re-ingest, or update NVIDIA_EMBED_MODEL."
     - If no stored metadata (new collection): no-op (collection was just created with current model)

   - `def add(self, chunks: list[dict], doc_id: str)`:
     - Extracts texts from chunks: `[c["text"] for c in chunks]`
     - Calls `self._embedder.embed(texts)` to get embeddings
     - Generates IDs: `f"{doc_id}_chunk_{i}"`
     - Generates metadatas: `{"doc_id": doc_id, "page_num": c["page_num"], "chunk_type": c.get("chunk_type", "text"), "chunk_index": c.get("chunk_index", i)}`
     - Calls `self._collection.add(ids=ids, embeddings=embeddings, documents=texts, metadatas=metadatas)`

   - `def query(self, query_text: str, n_results: int = 5, doc_id: str | None = None) -> dict`:
     - Embeds query: `self._embedder.embed_single(query_text)`
     - Builds `where` filter: `{"doc_id": doc_id}` if doc_id provided, else None
     - Calls `self._collection.query(query_embeddings=[embedding], n_results=n_results, where=where)`
     - Returns raw ChromaDB result dict

   - `def delete_by_doc(self, doc_id: str)`:
     - Calls `self._collection.delete(where={"doc_id": doc_id})`

   - `def count(self) -> int`:
     - Returns `self._collection.count()`

Imports:
```python
import chromadb
from chromadb.config import Settings as ChromaSettings
from core.embedder import Embedder
```

Note: Use `ChromaSettings` alias to avoid conflict with `core.config.Settings`.
