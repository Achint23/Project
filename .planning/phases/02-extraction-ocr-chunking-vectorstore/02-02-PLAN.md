  <name>Task 1: Create core/chunker.py — structure-aware token-based chunker</name>
  <files>core/chunker.py</files>
  <read_first>core/extractor.py (output format), core/config.py</read_first>
  <action>
Create `core/chunker.py` with:

1. Module-level tokenizer setup:
   ```python
   import tiktoken
   _ENCODING = tiktoken.get_encoding("cl100k_base")
   def _count_tokens(text: str) -> int:
       return len(_ENCODING.encode(text))
   ```

2. `chunk_text(text: str, doc_id: str, page_num: int, max_tokens: int = 700, overlap_tokens: int = 100) -> list[dict]`:
   - Split text on `\n\n` (paragraph boundaries) first
   - Accumulate paragraphs into a chunk until adding the next paragraph would exceed `max_tokens`
   - When a chunk is full, emit it and start the next chunk with overlap (last N tokens worth of text from previous chunk)
   - If a single paragraph exceeds `max_tokens`, split it on `\n` (line boundaries); if still too large, split on sentence boundaries (`. `)
   - Detect headings: lines that are short (<80 chars), don't end with punctuation, and precede a `\n\n` — keep headings attached to the following paragraph (never emit a heading as its own chunk)
   - Each returned dict: `{"text": str, "doc_id": str, "page_num": int, "chunk_type": "text", "chunk_index": int}`

3. `chunk_document(pages: list[dict], doc_id: str) -> list[dict]`:
   - Takes output from `extract_document()` (list of dicts with keys: text, chunk_type, page_num)
   - For items with `chunk_type == "table"`: emit as-is (atomic, never split) with added `doc_id` and `chunk_index`
   - For items with `chunk_type` in ("text", "ocr"): pass through `chunk_text()`
   - Assign sequential `chunk_index` across all chunks in the document (global counter)
   - Return flat list of all chunk dicts

Key design:
- Token counting via tiktoken `cl100k_base` (close enough for Llama-3 tokenization budgeting)
- Default max_tokens=700 (middle of 500-800 range, leaves room for overlap on both sides)
- Default overlap_tokens=100 (middle of 100-150 range)
- Heading detection heuristic: line length <80, no trailing `.!?;:`, not all-whitespace
