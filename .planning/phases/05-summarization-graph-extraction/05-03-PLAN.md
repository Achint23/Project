  <files>ui/summary_view.py, ui/graph_view.py</files>
  <action>
1. **ui/summary_view.py** — Create the summary view partial (per D-08, D-10):

   - Import: `streamlit as st`, `openai`, `from pipelines.summarize import SummaryResult, run_summarize`
   - Define `render_summary_view(vectorstore, nim_client)`:
     - Get document list from `st.session_state.get("documents", [])`
     - If no documents, show `st.info("Upload a document first to generate summaries.")`; return
     - Create a `st.selectbox` for document selection — display filename, use doc_id as value. Build options from the documents list: `{doc["filename"]: doc["doc_id"] for doc in documents}` pattern
     - Add a `st.button("📝 Summarize")` (key="summarize_btn")
     - When clicked, wrap in `with st.status("Summarizing...", expanded=True) as status:` (per D-10):
       - Call `run_summarize(doc_id, vectorstore, nim_client)`
       - If `result.error`: `st.error(result.error)`; `status.update(label="Summarization failed", state="error")`
       - Else: `status.update(label="Summary complete!", state="complete")`
       - Show method badge: `st.caption(f"Method: {result.method} | Chunks: {result.chunk_count}")`
       - Render summary: `st.markdown(result.summary)` (per D-01, summary has bolded key points)
     - Handle openai exceptions with `st.error()` (same 5 exception types as chat.py: RateLimitError, AuthenticationError, APIConnectionError, APITimeoutError, APIStatusError)

2. **ui/graph_view.py** — Create the graph view partial (per D-08, D-09, D-10):

   - Import: `streamlit as st`, `pandas as pd`, `openai`, `from pipelines.graph import GraphExtraction, GraphResult, run_graph_extraction`, `from streamlit_agraph import agraph, Node, Edge, Config`
   - Define entity type color map (per RESEARCH.md):
     ```python
     _TYPE_COLORS = {
         "PERSON": "#4CAF50", "ORG": "#2196F3", "PROCESS": "#FF9800",
         "SYSTEM": "#9C27B0", "CONCEPT": "#607D8B", "DOCUMENT": "#795548",
         "ROLE": "#00BCD4",
     }
     ```
   - Define `_render_tables(extraction: GraphExtraction)`:
     - Use `st.tabs(["Entities", "Relationships", "Process Steps", "Decision Points", "Business Rules"])`
     - For each tab, convert the Pydantic model list to a list of dicts using `.model_dump()`, then render with `st.dataframe(pd.DataFrame(data))` if non-empty, else `st.info("None found.")`
   - Define `_render_agraph(extraction: GraphExtraction)`:
     - Guard: if no entities, `st.info("No entities to visualize.")`; return
     - Build `Node` list from entities: `Node(id=e.name, label=e.name, size=25, color=_TYPE_COLORS.get(e.type, "#999"), title=f"{e.type}: {e.description}")`
     - Build `Edge` list from relationships: `Edge(source=r.source, target=r.target, label=r.relation, title=r.description)`
     - Create `Config(width=750, height=500, directed=True, physics=True, hierarchical=False)`
     - Call `agraph(nodes=nodes, edges=edges, config=config)`
   - Define `_render_process_mermaid(process_steps)`:
     - Guard: if no steps, return
     - Build mermaid flowchart string: `flowchart TD`, each step as a node, sequential edges between steps
     - Render with `st.markdown(mermaid_str)` — Streamlit 1.56.0 supports native mermaid
   - Define `render_graph_view(vectorstore, nim_client)`:
     - Get document list from `st.session_state.get("documents", [])`
     - If no documents, show `st.info("Upload a document first to extract graph data.")`; return
     - Create `st.selectbox` for document selection (same pattern as summary view, use unique key="graph_doc_select")
     - Add `st.button("🔍 Extract Graph", key="extract_btn")`
     - When clicked, wrap in `with st.status("Extracting graph data...", expanded=True) as status:`
       - Call `run_graph_extraction(doc_id, vectorstore, nim_client)`
       - If `result.error`: `st.error(result.error)`; `status.update(label="Extraction failed", state="error")`; return
       - `status.update(label="Extraction complete!", state="complete")`
       - Show stats: `st.caption(f"Entities: {result.entity_count} | Merges: {result.dedup_merges} | Chunks: {result.chunk_count}")`
     - Create inner tabs: `table_tab, graph_tab, process_tab = st.tabs(["📊 Table View", "🕸️ Graph View", "📋 Process Flow"])`
     - In table_tab: `_render_tables(result.extraction)`
     - In graph_tab: `_render_agraph(result.extraction)`
     - In process_tab: `_render_process_mermaid(result.extraction.process_steps)`
     - Handle openai exceptions with `st.error()` (same pattern as summary view)
  </action>
