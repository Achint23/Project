  <action>
Create `pipelines/graph.py` following the established pipeline pattern (per D-11).

**Imports:** `from __future__ import annotations`, `json`, `logging`, `dataclasses`, `Path`, `pydantic.BaseModel`, `pydantic.Field`, `rapidfuzz.fuzz`, `NIMClient`, `VectorStore`

**Pydantic models (per D-03, D-04, D-06):**
- `Entity(BaseModel)`: `name: str`, `type: str` (one of PERSON, ORG, PROCESS, SYSTEM, CONCEPT, DOCUMENT, ROLE), `description: str`
- `Relationship(BaseModel)`: `source: str`, `target: str`, `relation: str`, `description: str`
- `ProcessStep(BaseModel)`: `step_number: int`, `name: str`, `description: str`, `actors: list[str] = Field(default_factory=list)`
- `DecisionPoint(BaseModel)`: `name: str`, `description: str`, `options: list[str] = Field(default_factory=list)`
- `BusinessRule(BaseModel)`: `name: str`, `description: str`, `condition: str = ""`, `action: str = ""`
- `GraphExtraction(BaseModel)`: `entities: list[Entity] = Field(default_factory=list)`, `relationships: list[Relationship] = ...`, `process_steps: list[ProcessStep] = ...`, `decision_points: list[DecisionPoint] = ...`, `business_rules: list[BusinessRule] = ...`

**Result dataclass:**
- `GraphResult`: `extraction: GraphExtraction | None = None`, `doc_id: str = ""`, `chunk_count: int = 0`, `entity_count: int = 0`, `dedup_merges: int = 0`, `method: str = "single_pass"`, `error: str | None = None`

**Constants:**
- `DEDUP_THRESHOLD = 85` (per D-07)

**Helper: `_format_pydantic_errors(e: Exception) -> str`:**
Convert Pydantic validation errors to human-readable sentences the LLM can understand (per RESEARCH.md Pitfall 4). E.g., `"Field 'entities[2].type' must be one of PERSON, ORG, ... but got 'Organization'."` Use `e.errors()` if it's a `ValidationError`, otherwise `str(e)`.

**Helper: `_extract_with_retry(context: str, nim_client: NIMClient) -> GraphExtraction` (per D-06, D-13):**
1. Load `prompts/graph_extract.txt`, format with `context=context`
2. Call `nim_client.chat(messages=[{"role": "user", "content": prompt}], temperature=0.2, max_tokens=4096, json_mode=True)`
3. Parse response: `json.loads(response.choices[0].message.content)` → `GraphExtraction.model_validate(data)`
4. On `json.JSONDecodeError` or `pydantic.ValidationError`:
   - Load `prompts/graph_correct.txt`
   - Format with `original_output=raw` and `error_message=_format_pydantic_errors(first_error)`
   - Call `nim_client.chat(temperature=0.1, max_tokens=4096, json_mode=True)` (per D-13)
   - Parse and validate again — if this also fails, raise the error

**Helper: `deduplicate_entities(entities: list[Entity]) -> tuple[list[Entity], dict[str, str]]` (per D-07):**
- Compare within same entity type only using `fuzz.token_sort_ratio` at threshold 85
- Keep the longer name as canonical
- Return `(canonical_entities, name_map)` where `name_map` maps old names to canonical names
- name_map is needed to update relationship source/target and ProcessStep actors

**Helper: `_apply_dedup_to_graph(extraction: GraphExtraction, name_map: dict[str, str]) -> GraphExtraction`:**
- For each relationship: replace source/target with `name_map.get(source, source)` etc.
- For each process step: replace actors with canonical names
- Return updated extraction

**Main: `run_graph_extraction(doc_id: str, vectorstore: VectorStore, nim_client: NIMClient) -> GraphResult`:**
1. Call `vectorstore.get_all_by_doc(doc_id)`
2. If no chunks, return `GraphResult(error="No chunks found for this document.", doc_id=doc_id)`
3. Concatenate all chunk texts separated by `"\n\n"` (per D-05 — start with all chunks)
4. Call `_extract_with_retry(context, nim_client)`
5. Run `deduplicate_entities` on the extraction's entities
6. Run `_apply_dedup_to_graph` to update relationships and actors
7. Return `GraphResult(extraction=extraction, doc_id=doc_id, chunk_count=len(chunks), entity_count=len(extraction.entities), dedup_merges=original_count - deduped_count)`
8. Wrap in try/except, returning `GraphResult(error=str(e), doc_id=doc_id)` on failure

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM JSON Response → Pydantic Validation | Untrusted JSON from LLM crosses into validated domain objects |
| Document Content → LLM Prompt | Document text injected into extraction prompt; potential prompt injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | pipelines/graph.py | mitigate | LLM JSON output parsed with json.loads() (not eval()); validated with Pydantic schema — malformed data rejected or corrected |
| T-05-05 | Information Disclosure | prompts/graph_extract.txt | accept | Prompt contains schema description only, no secrets; single-user POC |
| T-05-06 | Denial of Service | pipelines/graph.py | mitigate | Self-correction limited to one retry (not unbounded); NIMClient retry handles rate limits |
| T-05-07 | Tampering | pipelines/graph.py entity dedup | accept | rapidfuzz is a well-maintained C++ library; dedup operates on LLM-extracted entity names from user's own documents |
</threat_model>
