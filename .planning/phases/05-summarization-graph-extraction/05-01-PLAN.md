<task type="auto">
  <name>Task 2: Summarization pipeline module and tests</name>
  <files>pipelines/summarize.py, tests/test_summarize_pipeline.py</files>
  <action>
1. **pipelines/summarize.py** — Create the summarization pipeline module (per D-11) following the `run_query` pattern from `pipelines/query.py`:

   - Import: `from __future__ import annotations`, `logging`, `dataclasses`, `Path`, `NIMClient`, `VectorStore`
   - Use `tiktoken` `cl100k_base` for token counting (already in stack, same as chunker)
   - Define `TOKEN_BUDGET = 6000` constant (per D-02)
   - Define `SummaryResult` dataclass with fields: `summary: str`, `doc_id: str`, `chunk_count: int`, `method: str` ("direct" or "map_reduce"), `error: str | None = None`
   - Define `_count_tokens(text: str) -> int` helper using `tiktoken.encoding_for_model("gpt-4")` (cl100k_base)
   - Define `_summarize_direct(text: str, nim_client: NIMClient) -> str`:
     - Load `prompts/summary_reduce.txt`, format with `text=text`
     - Call `nim_client.chat(messages=[{"role": "user", "content": prompt}], temperature=0.3, max_tokens=1024)` (per D-14)
     - Return `response.choices[0].message.content`
   - Define `_map_reduce(chunks: list[dict], nim_client: NIMClient) -> str`:
     - Load `prompts/summary_map.txt`
     - For each chunk: format prompt with `text=chunk["text"]`, call `nim_client.chat(temperature=0.3, max_tokens=512)`, collect partial summary
     - Load `prompts/summary_reduce.txt`, format with combined partials joined by `"\n\n---\n\n"`
     - Call `nim_client.chat(temperature=0.3, max_tokens=1024)` for the reduce step
     - Return final summary
   - Define `run_summarize(doc_id: str, vectorstore: VectorStore, nim_client: NIMClient) -> SummaryResult`:
     - Call `vectorstore.get_all_by_doc(doc_id)` to get all chunks
     - If no chunks, return `SummaryResult(summary="", doc_id=doc_id, chunk_count=0, method="direct", error="No chunks found for this document.")`
     - Calculate total tokens across all chunks using `_count_tokens`
     - If `total_tokens <= TOKEN_BUDGET`: concatenate all chunk texts, call `_summarize_direct`, return with `method="direct"`
     - Else: call `_map_reduce`, return with `method="map_reduce"`
     - Wrap in try/except, returning `SummaryResult(error=str(e))` on failure (same pattern as IngestResult)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → Pipeline | User selects doc_id for summarization; doc_id is content-hash (SHA-256), not user-supplied filename |
| LLM Response → Application | LLM output rendered as markdown in UI; potential XSS via injected markdown |
| Document Content → LLM Prompt | Document text injected into prompts; potential prompt injection via document content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | pipelines/summarize.py | accept | LLM summary is rendered via st.markdown which sanitizes HTML; doc content is from user's own uploads (single-user POC) |
| T-05-02 | Information Disclosure | prompts/summary_*.txt | accept | System prompt contains no secrets; single-user POC — no cross-user data leakage |
| T-05-03 | Denial of Service | pipelines/summarize.py | mitigate | Map-reduce on long docs makes N sequential LLM calls; rate-limit retries already handled by NIMClient._call_with_retry(); progress shown via st.status() |
</threat_model>
